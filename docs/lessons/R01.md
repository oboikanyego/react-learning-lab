# R01 — React fundamentals: JSX, rendering and project setup

Roadmap issue: https://github.com/oboikanyego/software-engineer-learning-roadmap/issues/6

## Goal

Create a React + TypeScript application from scratch and explain React's mental model without relying on Angular patterns.

## Start here

From the repository root on this branch:

```bash
node --version
npm --version
npm create vite@latest . -- --template react-ts
npm install
npm run dev
```

If Vite warns that the directory is not empty, choose the option to continue while keeping the existing repository files.

## Concepts to learn

- JSX and expressions
- Functional components
- Component rendering and re-rendering
- Props at a basic level
- Component composition
- Vite + React + TypeScript project structure

## Hands-on target

Build a small profile/dashboard screen using reusable components such as:

- Header
- ProfileCard
- SkillList

Do not add routing, TanStack Query, Zustand, or other future-track topics yet.
